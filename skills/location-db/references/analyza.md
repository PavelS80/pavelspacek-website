# Analýza scénáře — checklist před scoutem

Než začneš hledat lokace, projdi scénář a vyplň:

## Žánr a období
- **Žánr:** pohádka / period drama / fantasy / historie / mix
- **Období:** ranně středověké / vrcholná gotika / renesance / baroko / smíšené
- **Tón:** světlý / temný / romantický / syrový / pohádkově ironický

## Architektonický klíč
- Hrad: kamenný palác / dřevěné prvky / klenby / fresky?
- Město: kámen / omítka / dřevo / podloubí?
- Lid: roubené chalupy / hlinité / kamenné?

## Krajina
- Hory / pahorkatina / rovina / les / pobřeží / step?
- Vegetace: bukový/smrkový/smíšený les; pole/louky?
- Voda: řeka/potok/jezero/moře?

## Atmosféra
- Mlha / sluneční / temno / podzim / léto?
- Roční období v příběhu vs. natáčení (sezónní výzva)?

## Speciální požadavky scénáře (= dramaturgicky kritická místa)
- Specifické popisy lokace (např. "omšelý mlýn schovaný v lese")?
- Akční scény (chase, souboj, voda, výška)?
- Komparz size a logistika?
- Děti / zvířata?
- Noční / denní poměr?

## Dramaticky nejdůležitější lokace (= scoutovat první)
- Zpravidla 2–3 lokace, kde se odehrají klíčové dramatické momenty.
- Tyto určují vizuální koncept celého filmu — najít je TOP priorita.

## Logistické constraints
- Maximální vzdálenost od základny štábu?
- Hlavní base camp (Praha / Brno / Bratislava / Liptov)?
- Maximum company moves?
- Rozpočet (low / mid / high)?
- Natáčecí dny?

## Co se NESMÍ v záběru
- Moderní prvky (kabely, satelity, asfalt, dopravní značky)?
- Specifické věci, které dramaturgicky narušují?

## Output této analýzy
Po vyplnění jdi na výběr master motivů (typicky 4–8 z 15) → najdi 10–20 lokací/motiv → karta + skóre → HTML.
